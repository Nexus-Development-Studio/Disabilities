# Disabilities

Gain disabilities with a set timer, directly on your server!

 --- 

## Disabilities
| Disability name | Description |
|---|---|
| ADHD | Items randomly move in your inventory. |
| Amputated Offhand | You cannot use your offhand. |
| Amputated Leg | You cannot move without jumping. |
| Asthma | Eating too much sugar will poison you. |
| Blind | You cannot see anything. |
| Brain Palsy | You randomly move or click. |
| Cancer | Your max health slowly decreases over time. |
| Deaf | You cannot hear anything. |
| Dementia | Items randomly move in your inventory. |
| Diabetes | Eating too much sugar will poison you. |
| Mute | You cannot talk in the chat. |
| Narcolepsy | You randomly fall asleep. |
| Schizophrenia | You hear sounds of things that aren't there. |
| Seizures | Low health or hunger can cause you to have seizures. |
| Short | You get shorter and your reach is reduced. |
| Tourette's | You say random things in the chat and your head moves randomly. |
| Many more to come! |

## Features
- Scoreboard display
- Customizable timer
- JSON persistent storage

## Commands
| Command name | Description |
|---|---|
| /disability give <player> <disability> | Give a disability to a player. |
| /disability remove <player> <disability> | Give a disability from a player. |
| /disability reset <player> | Reset a player's disabilities. |
| /disability reload | Reload the plugin configuration. |
| /disability list <player> | Show a player's disabilities. |
| /disability next | Skip the timer to the next disability. |

## Configuration
You can configure the timer in the configuration.
